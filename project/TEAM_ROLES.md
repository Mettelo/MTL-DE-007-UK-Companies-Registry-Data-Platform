# Suggested Team Roles

Recommended team size: **3–5 members**.

## API / Ingestion Engineer
Owns:
- API client;
- authentication;
- request handling;
- pagination;
- retries;
- rate-limit handling.

## Data Platform Engineer
Owns:
- raw persistence;
- incremental loading;
- pipeline run metadata;
- local database/storage;
- orchestration/run flow.

## Data Modelling Engineer
Owns:
- staging;
- relational modelling;
- SIC structures;
- filing models;
- curated marts.

## Data Quality Engineer
Owns:
- profiling;
- automated tests;
- reconciliation;
- exception reporting.

## Technical Lead / Data Product Engineer
May be combined with another role.

Owns:
- architecture coherence;
- integration;
- delivery plan;
- analytical validation;
- documentation/handover;
- final QA.

Every member must contribute technically.
