# 04 — Pipeline & Data Quality

Document:
- execution order;
- first-load behaviour;
- refresh behaviour;
- idempotency;
- logging;
- API failure handling;
- validation;
- automated tests;
- reconciliation;
- known exceptions.

Minimum quality domains:
- uniqueness;
- completeness;
- validity;
- consistency;
- referential integrity;
- API/raw-to-model reconciliation.
