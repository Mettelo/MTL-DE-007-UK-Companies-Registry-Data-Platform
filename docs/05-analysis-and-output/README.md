# 05 — Analysis & Output Validation

Use curated models to prove the data platform is useful.

Include a concise set of outputs covering several of:
- company status;
- incorporation trends;
- SIC distribution;
- filing activity;
- filing categories;
- filing recency;
- attribute completeness.

For each output document:
- metric;
- model used;
- filters;
- result;
- interpretation;
- limitation.

Do not turn this into a dashboard-first project.
